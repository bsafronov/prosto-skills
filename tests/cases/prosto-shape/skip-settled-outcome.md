# Skip an Already Settled Outcome

## Given

A durable, approved product brief already defines one observable user outcome, representative examples, product rules, success evidence, non-goals, and no open product questions.

## When

The user asks to contract or implement that outcome.

## Then

The agent does not repeat product discovery through `prosto-shape` and passes the existing source to `prosto-contract` or the requested delivery path.
