# Approve One Durable Outcome

## Given

A raw checkout idea contains two independent desired outcomes, while repository evidence answers factual questions but leaves material product choices unresolved.

## When

The agent shapes the idea with the user.

## Then

The agent recommends one primary end-user outcome, parks the other, asks no more than three independent product questions per round, gives a recommendation and end-user example for each, and chooses technical details autonomously. It saves one Outcome Brief with accepted choices and only useful product rationale, requests explicit approval after product ambiguity is exhausted, then returns the approved path and revision for `prosto-contract`.
