# Retain Selected Product Memory

## Given

A product discussion considers several options, accepts one for a user-visible reason, rejects one boundary, and parks one independent outcome.

## When

The agent freezes the approved Outcome Brief.

## Then

The brief records the accepted choice and useful product reason, the explicit non-goal, and the parked outcome. It omits raw conversation, technical speculation, and rejected ideas whose rationale cannot affect later product work.
