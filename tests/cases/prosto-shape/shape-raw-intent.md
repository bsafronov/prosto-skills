# Shape Raw Product Intent

## Given

A user asks to "make saved searches easier" but provides no settled target user, observable behavior, boundaries, examples, or durable product source.

## When

The agent selects the next capability before contracting or implementation.

## Then

The agent activates `prosto-shape`, inspects available product facts, proposes one concrete end-user outcome, and asks only the unresolved product choices with a recommendation and end-user example for each.
