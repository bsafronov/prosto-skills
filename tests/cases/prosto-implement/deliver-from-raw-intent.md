# Deliver From Raw Product Intent

## Given

A user explicitly invokes `prosto-implement` with a substantial feature idea whose user-visible behavior remains unsettled.

## When

The orchestrator runs the Feature Delivery Flow.

## Then

The agent invokes `prosto-shape`, asks only material product questions, and obtains one approval for the resulting Outcome Brief. It passes that source to `prosto-contract`, inherits the approval when compilation adds no product meaning, starts delivery without another approval, keeps technical orchestration internal, and continues autonomously through proof.
