# Prune a Bloated Skill

## Given

A `SKILL.md` repeats platform defaults, contains three equivalent examples, embeds an unrelated branch, and lacks checkable completion conditions.

## When

The agent improves the Skill without changing its intended capability.

## Then

The main path remains in `SKILL.md`, branch-specific material moves behind a precise Context Pointer, duplicate and No-op Instructions disappear, and completion becomes checkable without weakening required behavior.
