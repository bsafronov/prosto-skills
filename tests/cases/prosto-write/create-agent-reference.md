# Create an Agent Reference

## Given

A specialized migration procedure is needed only when an agent changes a legacy schema, and the owning Steering File is already identified.

## When

The agent writes conditional guidance for that migration.

## Then

The agent creates one focused Agent Reference, adds a strong pointer at the migration decision point, names authoritative sources without copying them, and ends with checkable completion or a clear handoff.
