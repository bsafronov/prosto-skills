# Shrink a Steering File

## Given

An `AGENTS.md` always loads long release, database, and frontend procedures although each applies to a different task class.

## When

The agent reduces permanent Context Load while preserving discoverability.

## Then

Broad rules remain in `AGENTS.md`; conditional procedures move to focused Agent References; each branch has an available pointer naming what to load, when to load it, and where it lives; duplicated instructions are removed.
