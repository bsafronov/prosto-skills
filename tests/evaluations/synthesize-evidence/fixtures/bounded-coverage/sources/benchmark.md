# Loom Queue benchmark report
Owner: Loom Queue performance team. Run ID LQ-17, 2026-08-16, version 2.4.

Peak memory was 40% lower than version 2.3 in that run.
No production latency measurements, cold-cache runs, or failure-recovery tests were performed.
