# Promote Skills through evidence

Every new Skill will begin as an Experimental Skill hidden from normal installation. It becomes a Stable Skill only after its Quality Gate produces evidence and a Maintainer approves Promotion, allowing agents to create and improve Skills without exposing unproved behavior to normal installs. Deterministic CI blocks schema, invocation, reference, install, script, and case-structure failures; agent evaluation of Trigger Cases, Anti-trigger Cases, Composition Cases, and Outcome Cases supplies separate Promotion evidence without paid or nondeterministic model calls in normal CI. Each required case runs twice on one declared harness and model, with disagreement failing Predictability. New Skills and invocation or Composition changes also receive one compatibility run on Codex, Claude Code, Cursor, and OpenCode; compatible patch changes use the reference harness only. Evaluation Reports stay in pull-request or CI artifacts. Promotion remains a separate Maintainer action.
