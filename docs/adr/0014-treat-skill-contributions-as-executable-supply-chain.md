# Treat Skill contributions as executable supply chain

Public Skill contributions will be treated as executable supply-chain changes because agents can follow instructions and run bundled scripts with ambient permissions. Pull-request workflows receive read-only permissions and no secrets; third-party Actions are pinned; `main` requires pull requests and CI while blocking force pushes and deletion; executable scripts require Maintainer review; dependencies receive scheduled updates; and private vulnerability reporting is documented.
