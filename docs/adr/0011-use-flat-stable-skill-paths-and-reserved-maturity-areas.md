# Use flat stable Skill paths and reserved maturity areas

Stable Skills will live directly under `skills/`, Experimental Skills under `skills/.experimental/`, and Maintainer-only Skills under `skills/.system/`. Skill names remain flat verb-object names instead of encoding taxonomy in paths. Promotion moves an Experimental Skill into the stable area; hidden metadata prevents Experimental and Maintainer-only Skills from appearing in normal installs.
