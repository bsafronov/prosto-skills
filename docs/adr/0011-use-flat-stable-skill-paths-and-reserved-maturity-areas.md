# Use flat stable Skill paths and reserved maturity areas

Stable Skills will live directly under `skills/`, Experimental Skills under `skills/.experimental/`, and Maintainer-only Skills under `skills/.system/`. Stable names remain flat and carry tags in metadata instead of path categories, avoiding taxonomy-driven path changes. Promotion moves an Experimental Skill into the stable area; hidden metadata prevents experimental and system Skills from appearing in normal installs.
