# Separate observation, change, and Promotion

Core Skills will not combine unrestricted observation, mutation, evaluation, and Promotion. Review, evaluation, reflection, and routing remain read-only; writing changes only the named agent-facing artifact; improvement applies one user-selected candidate without Promotion; Promotion changes maturity only after explicit Maintainer confirmation. This separation lets agents improve the Skill Ecosystem without silently rewriting or releasing it.
